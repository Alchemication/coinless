# Street Fighter II: Champion Edition

Arcade, `sf2ce`. Source: [PStroffolino's guide](https://gamefaqs.gamespot.com/arcade/583628-street-fighter-ii-champion-edition/faqs/844); select Champion Edition information because it covers multiple releases.

Six actions: light/medium/heavy punch, then light/medium/heavy kick. Quarter-circle-forward means down → down-forward → forward.

Practice Ryu/Ken fireballs on both sides, then blocking and grounded movement. Add one verified punish combo. Save states support repetition; no arcade training menu is assumed.
