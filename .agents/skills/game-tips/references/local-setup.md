# Local setup

Player uses PS4 controllers. For actual bindings, inspect project `cfg/default.cfg` and `cfg/<game>.cfg`; game overrides take priority. Do not assume earlier keyboard suggestions were applied.

Installed MAME supports saves for Heaven's Gate, Cadillacs, and SF2; Tekken 3 saves are unsupported. Recheck after updates with `mame <name> -listxml`. Idle P2 practice retains health/time limits.

See the project README for launch commands and [MAME controls](https://docs.mamedev.org/usingmame/defaultkeys.html) for save/input bindings.
